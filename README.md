# UbuNurse

UbuNurse is a cross-platform mobile app designed to improve home nursing assessments. It helps nursing staff collect patient data in a structured way, follow Gordon's Functional Health Patterns, and review patient evolution through clear visual charts.

## Overview

Home nursing often still relies on paper notes and fragmented tools. UbuNurse was created to modernize that workflow with a mobile, offline-first application that improves efficiency, consistency, and readability during home visits.

The project was developed as a cross-platform solution using web technologies and hybrid app tooling, with a focus on usability in real field conditions.

## Key Features

- Structured patient assessments based on Gordon's Functional Health Patterns.
- Offline-first local storage for use in rural or low-connectivity environments.
- Automatic synchronization with a remote database when a connection is available.
- Patient history management with multiple questionnaires per patient.
- Visual evolution charts to compare assessment results over time.
- Mobile-friendly interface designed for tablets and smartphones.
- Cross-platform approach for Android, iOS, and Windows Phone.

## Why UbuNurse Exists

The project was built for home nursing visits, where professionals need a fast, clear, and reliable way to collect information, interpret results, and continue care without depending on paper notes or incomplete desktop tools.

The goal is simple: spend less time organizing data and more time caring for the patient.

If you want to publish the website version on GitHub Pages, place the `index.html` file at the root of the repository and enable GitHub Pages from the repository settings.

If you want to work with the mobile app code, clone the repository and open the project in your preferred editor or hybrid app workflow.
